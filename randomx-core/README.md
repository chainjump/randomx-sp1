# randomx-sp1 core

This is the internal cache, dataset, program-generation, and VM-state crate
used by the public `randomx-sp1` library. It is not a supported public API and
is not published independently.

This code began as a fork of RustDom-X 1.1.0 and remains licensed under the
GPL-3.0. See the repository-level `ATTRIBUTION.md` and this directory's
`LICENSE` for provenance and license details.
