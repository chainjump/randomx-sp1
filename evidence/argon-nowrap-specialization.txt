RandomX Argon2 statically non-wrapping reference optimization, actual SP1 RV64IM execution
UTC date: 2026-07-27

Statement preserved
-------------------
The guest derives the complete 256 MiB RandomX Argon2 cache from the epoch
seed, derives every requested dataset item on demand, executes all eight
256-instruction programs for 2,048 iterations each, implements every CFROUND
mode, checks the official hash, and commits the same 32 bytes.

Accepted change
---------------
The fixed RandomX cache loop is compile-time specialized by Argon pass and
slice. In the first pass, every reference precedes the current block and the
reference start is zero. In the final slice of later passes, the reference
start is also zero and the reference area is shorter than the 262,144-block
lane. Therefore `start_position + relative_position` is already in range in
those specialized cases and does not need a lane mask. The remaining later
pass slices retain the mask because their reference positions can wrap.

A debug assertion checks the non-wrapping bound in host/debug executions. No
cache input or commitment was added, no cache block was omitted, and no
CFROUND path was changed.
